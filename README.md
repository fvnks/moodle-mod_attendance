# Módulo de Asistencia para Moodle

Este plugin de asistencia para Moodle ha sido adaptado específicamente para el contexto educacional chileno, incorporando características y configuraciones relevantes para instituciones educativas en Chile.

## Características

- **Interfaz en español chileno**: Completamente adaptado al español de Chile.
- **Configuración para el contexto chileno**: Incluye valores predeterminados y opciones típicas del sistema educativo chileno.
- **Porcentaje mínimo configurable**: Permite establecer el porcentaje mínimo de asistencia requerido (predeterminado: 85%).
- **Estados de asistencia personalizables**: Presente, Ausente, Atrasado y Justificado, con puntuaciones configurables.
- **Bloqueo automático de sesiones**: Configura el bloqueo automático de sesiones pasadas.
- **Alertas visuales**: Identificación de estudiantes con baja asistencia mediante alertas visuales.
- **Actualizaciones automáticas**: Sistema integrado para comprobar y notificar sobre nuevas versiones disponibles.

## Instalación

1. Descarga el plugin desde este repositorio.
2. Descomprime el archivo en la carpeta `/mod/` de tu instalación de Moodle.
3. Renombra la carpeta a `attendance` si es necesario.
4. Accede a la página de notificaciones de Moodle como administrador para completar la instalación.

## Configuración

1. Accede a Administración del sitio > Plugins > Módulos de actividad > Asistencia.
2. Configura las opciones según tus necesidades:
   - Porcentaje mínimo de asistencia
   - Bloqueo automático de sesiones
   - Estados de asistencia y sus puntuaciones
   - Configuración de informes y alertas
   - Parámetros para actualizaciones desde GitHub

## Requisitos

- Moodle 4.1 o superior
- PHP 7.4 o superior
